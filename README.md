# CE_Morning — 새벽예배 담당자 자동 배정

교회 새벽예배 **설교자 · 방송실**, 그리고 **수요현관 · 토요찬양** 담당을 로테이션 명단대로
자동으로 채워 주는 구글 시트용 프로그램(Google Apps Script)입니다.

---

## 무엇을 해 주나

- `로테이션` 탭에 이름을 적어 두면 **적은 순서대로** 돌아가며 배정합니다.
- **토요일은 설교·방송을 별도 명단**으로 돌릴 수 있습니다. (비워 두면 평일 명단으로 그냥 이어서 돕니다.)
- 같은 날 **설교자와 방송실이 같은 사람**이 되면 방송실을 **다음날과 맞바꿉니다**.
- `달력(예외자)` 탭에 **그날 빠지는 사람**을 적어 두면 그 사람은 건너뛰고 **다음 순서자**가 들어갑니다.
- 달력에 **`휴일`** 이라고 적으면 그날은 **아무도 배정하지 않고 칸을 비워 둡니다.** 손으로 직접 적으시면 됩니다.
- 결과는 `2026-09` 같은 이름의 시트에, 지금 쓰시던 표와 같은 모양으로 그려집니다.

---

## 설치 (10분)

### 방법 A — 편집기에 붙여 넣기 (제일 간단)

1. 담당표 구글 시트를 엽니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**.
3. 왼쪽 `Code.gs` 안의 내용을 모두 지우고, 이 저장소의 [`dist/Code.gs`](dist/Code.gs) 를
   통째로 복사해 붙여 넣습니다.
4. 저장(💾)한 뒤 시트로 돌아와 **새로고침**합니다.
5. 상단에 **`새벽예배 배정`** 메뉴가 생깁니다.

> 처음 메뉴를 누르면 구글이 권한을 묻습니다.
> `고급 → (안전하지 않은 페이지)로 이동` 을 눌러 본인 계정으로 승인하면 됩니다.
> 이 스크립트는 **이 시트 하나만** 읽고 씁니다.

### 방법 B — clasp 로 올리기 (개발용)

```bash
npm i -g @google/clasp
clasp login
clasp clone <스크립트 ID>     # 또는 clasp create --type sheets
clasp push
```

`src/*.gs` 를 고친 뒤에는 `npm run build` 로 `dist/Code.gs` 도 같이 갱신해 주세요.

## 쓰는 순서

### 1. 초기 설정 만들기

메뉴 **새벽예배 배정 → ① 초기 설정 만들기**. 탭 세 개가 만들어집니다.
배정을 돌리면 탭이 **표 → `달력(예외자)` → `로테이션` → `설정`** 순서로 정리됩니다.

> **이미 쓰고 계시던 시트라면** 이 메뉴를 한 번 더 누르세요. 기존 내용은 그대로 두고
> 빠진 명단 열과 설정 항목만 채워 넣습니다. 새 명단 열은 기존 명단 **바로 옆**에
> 들어가고, 안내 문구는 오른쪽으로 밀립니다.

| 탭 | 하는 일 |
|---|---|
| `설정` | 로테이션 시작일, 새벽예배 요일, 토요 별도 요일, 수요현관·토요찬양 요일 |
| `로테이션` | 설교 / 방송 / 토요설교 / 토요방송 / 수요현관 / 토요찬양 명단 |
| `달력(예외자)` | 그날 빠지는 사람 · 휴일 표시 |

### 2. `설정` 탭 확인

| 항목 | 예시 | 설명 |
|---|---|---|
| 로테이션 시작일 | `2026-08-31` | **이 날짜에 각 명단의 1번이 섭니다.** 한 번 정하면 웬만하면 바꾸지 마세요. 바꾸면 그 뒤 순서가 전부 밀립니다. |
| 새벽예배 요일 | `월,화,수,목,금,토` | 설교자·방송실을 배정할 요일 |
| 토요 별도 요일 | `토` | 이 요일은 `토요설교`·`토요방송` 명단으로 따로 돕니다 |
| 수요현관 요일 | `수` | 넷째 줄에 수요현관 담당이 들어갈 요일 |
| 토요찬양 요일 | `토` | 같은 넷째 줄에 토요찬양 담당이 들어갈 요일 |

### 3. `로테이션` 탭에 이름 넣기

```
설교        방송      토요설교    토요방송    수요현관    토요찬양
김목사      정집사    강목사      임집사      오권사      서집사
이목사      김목사    조전도사    강목사      윤집사      류집사
박전도사    한집사
최목사
```

위에서 아래로 순서대로 돌아갑니다. 명단마다 인원 수는 서로 달라도 됩니다.

**명단은 열 위치가 아니라 1행 머리글 이름으로 찾습니다.** 열 순서를 바꾸거나
중간에 열을 끼워 넣으셔도 됩니다. `설교자` · `토요 설교` · `방송실` 처럼 조금 달라도
알아봅니다.

**뭔가 안 채워질 때는 메뉴 [명단·예외 점검]** 을 눌러 보세요. 명단마다 **몇 열에서
읽었는지**, 못 찾은 열은 무엇인지, 로테이션 탭 1행이 실제로 어떻게 적혀 있는지
그대로 보여 줍니다.

`토요설교` · `토요방송` 을 **비워 두면** 토요일도 평일 명단으로 그냥 이어서 돕니다.
이때는 배정을 마칠 때 "토요일도 [설교] 명단으로 이어서 돌았습니다" 라고 알려 주므로,
명단을 안 채운 걸 모르고 지나칠 일은 없습니다.
둘 중 하나만 채우셔도 됩니다 (예: 설교만 토요일 따로, 방송은 평일과 한 줄로).

넷째 줄 `수요/토요` 는 요일에 따라 내용이 바뀝니다 — 수요일 칸에는
`수요현관` 명단이, 토요일 칸에는 `토요찬양` 명단이 들어갑니다.

### 4. `달력(예외자)` 탭에 빠지는 사람 · 휴일 표시

날짜 **아래 칸**에 이름을 적습니다.

```
홍길동                 → 그날 설교·방송·수요현관 전부에서 빠짐
김집사(방송)           → 그날 방송실에서만 빠짐
홍길동, 김집사(방송)   → 쉼표로 여러 명
휴일                   → 그날은 아예 배정하지 않고 표의 칸을 비움 (직접 입력)
휴일(방송)             → 방송실 칸만 비움
```

괄호에 쓸 수 있는 역할: `설교` · `방송` · `수요현관` · `토요찬양` (안 쓰면 전부).
`설교` 는 평일과 토요일 설교 모두에, `방송` 은 평일과 토요일 방송 모두에 걸립니다.
`휴일` 대신 `휴무` · `없음` · `직접입력` 이라고 적어도 똑같이 동작합니다.

여름휴가처럼 며칠씩 이어지는 건 그 날짜 칸마다 같은 이름을 적어 주시면 됩니다.
(한 칸을 복사해서 여러 칸에 붙여 넣으면 빠릅니다.)

다른 달을 보려면 메뉴 **② 달력 다시 그리기**. **적어 둔 내용은 달을 바꿔도 남습니다.**

### 5. 배정하기

메뉴 **③ 이번 달 배정하기** (다른 달은 **④ 다른 달 배정하기…**, `2026-09` 형식으로 입력).

`2026-09` 시트가 만들어지고 표가 채워집니다. 이미 있으면 덮어씁니다.

## 배정 규칙

**순서대로 배정** — 기준일부터 새벽예배 요일마다 명단을 한 칸씩 내려가며 배정합니다.
여섯 명단이 각자 자기 순번을 따로 갖습니다.

**토요일 별도 명단** — 토요일은 `토요설교`·`토요방송` 으로 돕니다. 토요일을 빼도
평일 순번은 끊기지 않습니다 — 금요일 다음 차례가 그대로 월요일로 이어집니다.

**빠지는 사람은 건너뜀** — 그날 예외로 걸린 사람은 넘기고 다음 사람이 섭니다.
건너뛴 사람의 차례는 없어지지 않고 다음 바퀴에 돌아옵니다.

> 예) 명단이 `가·나·다` 이고 `나` 가 9/1 하루 휴가면
> 8/31 `가` → 9/1 `다` → 9/2 `가` → 9/3 `나`

**여러 명이 같은 날 빠져도 됩니다.** 날짜 칸에 쉼표로 이어 적으시면, 가능한 사람이
나올 때까지 명단을 계속 내려갑니다. 건너뛴 분들의 차례는 다음 바퀴에 그대로 돌아옵니다.

> 예) 명단이 `김·이·박·최·정` 이고 9/1 에 `이` 와 `박` 이 함께 빠지면
> 8/31 `김` → 9/1 `최` → 9/2 `정` → 9/3 `김` → 9/4 `이` → 9/5 `박`

**휴일은 통째로 건너뜀** — 달력에 `휴일` 이라고 적은 날은 아무도 배정하지 않고 칸을 비웁니다.
칸은 연한 노란색으로 표시되고 메모가 붙지만 **내용은 비어 있어 그대로 손으로 적으시면 됩니다.**

> 휴가와 다른 점: **휴가는 그 사람만 건너뛰고 다음 사람이 서지만, 휴일은 순번 자체가 멈춥니다.**
> 명단이 `가·나·다` 이고 9/1 이 휴일이면 8/31 `가` → 9/1 (빈칸) → 9/2 `나` → 9/3 `다`.
> 쉰 다음 예배에 원래 설 순서였던 분이 그대로 서게 됩니다.

**설교자와 방송실이 겹치면 교대** — 방송실 담당을 **다음날 방송실 담당과 맞바꿉니다.**
맞바꾼 결과가 또 겹치거나 상대가 그날 휴가·휴일이면 그 다음날로 밀어서 찾습니다.
**교대는 같은 명단 안에서만 합니다** — 토요일 충돌은 다음 토요일과 맞바꾸고,
평일 충돌은 다음 평일과 맞바꿉니다. 그래야 평일 사람이 토요일로 넘어가지 않습니다.

**넷째 줄(수요현관·토요찬양)은 겹쳐도 그냥 순서대로** — 그날 설교자나 방송실과 같은
사람이 되어도 손대지 않습니다. 다른 예배 순서라 한 사람이 맡아도 되기 때문입니다.
명단 순서가 그대로 지켜집니다.

**맞바꿀 상대가 없으면 그대로 둡니다.** 다른 사람을 대신 데려오지 않습니다.
그 칸은 **분홍색**으로 표시되고, 배정을 마칠 때 어느 날인지 알려 줍니다.
그 자리만 직접 정하시면 됩니다.

> 새벽예배가 주 6일이라, 명단 인원이 **6의 약수(1·2·3·6명)** 면 매주 같은 사람이
> 수요일(또는 토요일)에 걸립니다. 그러면 옮길 자리가 없어 교대가 안 됩니다.
> 겹침이 자꾸 풀리지 않으면 명단 인원 수를 한 명 늘리거나 줄여 보세요.
맞바꾼 칸에는 메모가 붙습니다 (셀 오른쪽 위 검은 삼각형).

**같은 결과가 반복 보장** — 순번을 어딘가에 저장해 두지 않고 **기준일부터 매번 새로 계산**합니다.
그래서 같은 달을 몇 번 다시 돌려도 결과가 같고, 8월 시트의 `8/31` 칸과 9월 시트의 `8/31` 칸에
항상 같은 이름이 들어갑니다.

**앞뒤 달 칸** — 첫 주·마지막 주에 걸치는 다른 달 날짜도 채우되 **회색으로** 표시합니다.

**채울 사람이 없을 때** — 그날 명단이 전원 예외면 칸을 비우고 **분홍색**으로 표시한 뒤,
배정이 끝날 때 어느 날인지 알려 줍니다. 명단 자체가 비어 있는 경우(예: 토요찬양을
아직 안 쓰심)는 그냥 빈 칸으로 두고 알리지 않습니다.

## 손으로 고치고 싶을 때

결과 시트는 그냥 셀을 고쳐 쓰시면 됩니다. **다만 그 달을 다시 배정하면 덮어써집니다.**
계속 유지해야 하는 변경이면 `달력(예외자)` 에 반영한 뒤 다시 돌리는 쪽이 안전합니다.

특별새벽기도회, 부흥회, 절기처럼 **매번 따로 정하시는 날**은 달력에 `휴일` 로 잡아 두세요.
그 칸은 다시 배정해도 계속 비어 있으므로, 손으로 적어 넣은 이름이 지워질 걱정 없이 쓰실 수 있습니다.

## 개발자용

```bash
npm test        # 테스트 85개 (배정 규칙 48, 달력 파싱 12, 시트 동작 25)
npm run preview # 시트 없이 터미널에서 9월 표 미리보기 (휴가·휴일 예시 포함)
npm run build   # src/*.gs -> dist/Code.gs
```

| 파일 | 역할 |
|---|---|
| `src/Rotation.gs` | 배정 규칙 (시트 API를 안 씁니다. Node 로 그대로 테스트됩니다) |
| `src/Sheets.gs` | 설정·명단·예외 읽기 |
| `src/Calendar.gs` | `달력(예외자)` 탭 그리기/읽기 (휴가·휴일이 전부 여기서 옵니다) |
| `src/Render.gs` | 월별 표 그리기 |
| `src/Setup.gs` | 초기 탭 만들기 |
| `src/Menu.gs` | 시트 상단 메뉴 |

`test/sheets.test.js` 는 구글 시트 API 를 흉내 낸 껍데기(`test/fakeSheets.js`) 위에서
초기 설정부터 월별 표 생성까지 실제로 한 번 돌려 봅니다. 서식은 확인하지 못하지만
값·메모·병합은 검사합니다.
