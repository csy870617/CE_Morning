# CE_Morning — 새벽예배 담당자 자동 배정

교회 새벽예배 **설교자 · 방송실**, 그리고 **수요백업 · 토요백업 · 현관안내** 담당을
로테이션 명단대로 자동으로 채워 주는 구글 시트용 프로그램(Google Apps Script)입니다.

---

## 무엇을 해 주나

- `로테이션` 탭에 이름을 적어 두면 **적은 순서대로** 돌아가며 배정합니다.
- **토요일은 설교·방송을 별도 명단**으로 돌릴 수 있습니다. (비워 두면 평일 명단으로 그냥 이어서 돕니다.)
- 같은 날 **설교자와 방송실이 같은 사람**이 되면 방송실을 **다음날과 맞바꿉니다**.
- **같은 사람이 그 달 같은 요일에 두 번까지만** 서게 순서를 바꿉니다 (설교·방송실 각각).
- `달력(예외자)` 탭에 **그날 빠지는 사람**을 적어 두면 그 사람은 건너뛰고 **다음 순서자**가 들어갑니다.
- 달력에 **`휴일`** 이라고 적은 날은 **`휴일(설교)`·`휴일(백업)` 명단**에서 들어갑니다.
  (그 명단을 비워 두면 예전처럼 빈 칸으로 남습니다.)
- **현관안내**는 수요일이 든 주마다 **세 명씩** 표 오른쪽 `I열` 에 들어갑니다.
- 결과는 `2026-09` 같은 이름의 시트에, 지금 쓰시던 표와 같은 모양으로 그려집니다.

## 설치 (10분)

### 방법 A — 편집기에 붙여 넣기 (제일 간단)

1. 담당표 구글 시트를 엽니다.
2. 메뉴에서 **확장 프로그램 → Apps Script**.
3. 왼쪽 `Code.gs` 안의 내용을 모두 지우고, 이 저장소의 [`dist/Code.gs`](dist/Code.gs) 를
   통째로 복사해 붙여 넣습니다.
4. 저장(💾)한 뒤 시트로 돌아와 **새로고침**합니다.
5. 상단에 **`새벽예배 배정`** 메뉴가 생깁니다.

> 처음 메뉴를 누르면 구글이 권한을 묻습니다.
> `고급 → (안전하지 않은 페이지)로 이동` 을 눌러 본인 계정으로 승인하면 됩니다.
> 이 스크립트는 **이 시트 하나만** 읽고 씁니다.

### 방법 B — clasp 로 올리기 (개발용)

```bash
npm i -g @google/clasp
clasp login
clasp clone <스크립트 ID>     # 또는 clasp create --type sheets
clasp push
```

`src/*.gs` 를 고친 뒤에는 `npm run build` 로 `dist/Code.gs` 도 같이 갱신해 주세요.

## 쓰는 순서

### 1. 초기 설정 만들기

메뉴 **새벽예배 배정 → 초기 설정 만들기**. 탭 세 개가 만들어집니다.
배정을 돌리면 탭이 **표 → `달력(예외자)` → `로테이션` → `설정`** 순서로 정리됩니다.

> **이미 쓰고 계시던 시트라면** 이 메뉴를 한 번 더 누르세요. **코드를 갱신한 뒤에도
> 한 번 눌러 주시면 됩니다.** 적어 두신 이름과 설정 값은 건드리지 않고 이것만 맞춥니다.
>
> - 빠진 명단 열·설정 항목을 채워 넣습니다. 새 명단 열은 기존 명단 **바로 옆**에
>   들어가고, 안내 문구는 오른쪽으로 밀립니다
> - 뜻이 달라진 예전 이름을 바꿉니다 (`수요현관` → `수요백업`, `토요찬양` → `토요백업`,
>   설정의 `수요저녁 요일` → `수요백업 요일`). `설교자` · `방송실` 처럼 그냥 다르게
>   쓰신 이름은 그대로 둡니다
> - `설정` 탭의 설명 칸과 `로테이션` 머리글 메모를 **최신 내용으로 맞춥니다**
>
> 무엇을 고쳤는지 안내창에 한 줄씩 나오고, 고칠 게 없으면 "이미 모두 있고 설명도
> 최신입니다" 라고 알려 줍니다.

| 탭 | 하는 일 |
|---|---|
| `설정` | 로테이션 시작일, 새벽예배 요일, 토요 별도 요일, 수요백업·토요백업 요일 (5개) |
| `로테이션` | 설교 / 방송 / 토요설교 / 토요방송 / 수요백업 / 토요백업 / 휴일(설교) / 휴일(백업) / 현관안내 명단 (9개) |
| `달력(예외자)` | 그날 빠지는 사람 · 휴일 표시 (달마다 저장됩니다) |

### 2. `설정` 탭 확인

| 항목 | 예시 | 설명 |
|---|---|---|
| 로테이션 시작일 | `2026-08-31` | **이 날짜에 각 명단의 1번이 섭니다.** 한 번 정하면 웬만하면 바꾸지 마세요. 바꾸면 그 뒤 순서가 전부 밀립니다. |
| 새벽예배 요일 | `월,화,수,목,금,토` | 설교자·방송실을 배정할 요일 |
| 토요 별도 요일 | `토` | 이 요일은 `토요설교`·`토요방송` 명단으로 따로 돕니다 |
| 수요백업 요일 | `수` | 넷째 줄에 `수요백업` 담당이 들어갈 요일. `현관안내` 날짜도 이 요일로 잡습니다 |
| 토요백업 요일 | `토` | 같은 넷째 줄에 `토요백업` 담당이 들어갈 요일 |

> 예전 이름 `수요현관 요일` · `토요찬양 요일` · `수요저녁 요일` 로 적혀 있어도 그대로 읽습니다.
> 초기 설정을 다시 눌러도 같은 뜻의 항목을 두 번 만들지 않습니다.

### 3. `로테이션` 탭에 이름 넣기

```
설교      방송     토요설교   토요방송   수요백업   토요백업   휴일(설교)  휴일(백업)  현관안내
김목사    정집사   강목사     임집사     오권사     서집사     한목사      노집사      고집사
이목사    김목사   조전도사   강목사     윤집사     류집사     차목사      사집사      남집사
박전도사  한집사                                                                      도집사
최목사                                                                                마집사
```

위에서 아래로 순서대로 돌아갑니다. 명단마다 인원 수는 서로 달라도 됩니다.

**명단은 열 위치가 아니라 1행 머리글 이름으로 찾습니다.** 열 순서를 바꾸거나
중간에 열을 끼워 넣으셔도 됩니다. `설교자` · `토요 설교` · `방송실` 처럼 조금 달라도
알아봅니다.

**뭔가 안 채워지면 배정을 마칠 때 알려 줍니다** — 어느 열을 못 찾았는지, 어느 명단이
비어 있는지, 달력에 적은 이름이 명단에 없는지(오타)까지 함께 나옵니다.

`토요설교` · `토요방송` 을 **비워 두면** 토요일도 평일 명단으로 그냥 이어서 돕니다.
이때는 배정을 마칠 때 "토요일도 [설교] 명단으로 이어서 돌았습니다" 라고 알려 주므로,
명단을 안 채운 걸 모르고 지나칠 일은 없습니다.
둘 중 하나만 채우셔도 됩니다 (예: 설교만 토요일 따로, 방송은 평일과 한 줄로).

넷째 줄 `수요/토요 서브` 는 요일에 따라 내용이 바뀝니다 — 수요일 칸에는
`수요백업` 명단이, 토요일 칸에는 `토요백업` 명단이 들어갑니다.

> 예전 머리글 `수요현관` · `토요찬양` 도 그대로 알아보니, 이미 쓰고 계시던 시트의
> 머리글을 굳이 고치지 않으셔도 됩니다.

`휴일(설교)` · `휴일(백업)` 은 달력에 `휴일` 로 잡은 날에만 쓰는 별도 명단입니다.
평일·토요일 순번과 따로 돌아갑니다.

`현관안내` 는 **수요일이 든 주마다 세 명씩** 표 오른쪽 `I열` 로 들어갑니다.

### 4. `달력(예외자)` 탭에 빠지는 사람 · 휴일 표시

날짜 **아래 칸**에 이름을 적습니다.

```
홍길동                 → 그날 설교·방송·수요백업·토요백업·현관안내 전부에서 빠짐
김집사(방송)           → 그날 방송실에서만 빠짐
홍길동, 김집사(방송)   → 쉼표로 여러 명
휴일                   → 그날은 아예 배정하지 않고 표의 칸을 비움 (직접 입력)
휴일(방송)             → 방송실 칸만 비움
```

괄호에 쓸 수 있는 역할: `설교` · `방송` · `수요백업` · `토요백업` · `현관안내` (안 쓰면 전부).
`설교` 는 평일과 토요일 설교 모두에, `방송` 은 평일과 토요일 방송 모두에 걸립니다.
`휴일` 대신 `휴무` · `없음` · `직접입력` 이라고 적어도 똑같이 동작합니다.

> **현관안내는 그냥 `휴일` 로는 비우지 않습니다.** 수요일을 휴일로 잡아도 그 주 현관안내는
> 그대로 돌아갑니다. 현관안내만 쉬게 하려면 `휴일(현관안내)` 라고 적어 주세요.

여름휴가처럼 며칠씩 이어지는 건 그 날짜 칸마다 같은 이름을 적어 주시면 됩니다.
(한 칸을 복사해서 여러 칸에 붙여 넣으면 빠릅니다.)

다른 달을 보려면 **달력 탭의 연월 칸(B1)** 을 누르고 목록에서 고르세요.
맨 위가 이번 달이고, 그 아래로 다음 6개월 · 지난 6개월이 들어 있습니다.
고르는 즉시 그 달 달력이 나옵니다.

> **적어 두신 내용은 달마다 남습니다.** 달을 옮기면 보던 달 내용이 저장되고,
> 돌아오면 그대로 다시 나옵니다. 적은 적 없는 달은 이름 칸이 비어 있습니다.
> 배정할 때는 달력이 어느 달을 보고 있든 그 달에 저장된 예외가 반영됩니다.

### 5. 배정하기

메뉴 **새벽설교 배정표 만들기**. 달력이 보고 있는 달이 기본으로 잡히니,
그대로 **[확인]** 을 누르면 됩니다. 다른 달을 배정하려면 `2026-09` 형식으로 적어 주세요.

`2026-09` 시트가 만들어지고 표가 채워집니다. 이미 있으면 덮어씁니다.

## 배정 규칙

**순서대로 배정** — 기준일부터 새벽예배 요일마다 명단을 한 칸씩 내려가며 배정합니다.
아홉 명단이 각자 자기 순번을 따로 갖습니다.

**토요일 별도 명단** — 토요일은 `토요설교`·`토요방송` 으로 돕니다. 토요일을 빼도
평일 순번은 끊기지 않습니다 — 금요일 다음 차례가 그대로 월요일로 이어집니다.

**빠지는 사람은 건너뜀** — 그날 예외로 걸린 사람은 넘기고 다음 사람이 섭니다.
건너뛴 사람의 차례는 없어지지 않고 다음 바퀴에 돌아옵니다.

> 예) 명단이 `가·나·다` 이고 `나` 가 9/1 하루 휴가면
> 8/31 `가` → 9/1 `다` → 9/2 `가` → 9/3 `나`

**여러 명이 같은 날 빠져도 됩니다.** 날짜 칸에 쉼표로 이어 적으시면, 가능한 사람이
나올 때까지 명단을 계속 내려갑니다. 건너뛴 분들의 차례는 다음 바퀴에 그대로 돌아옵니다.

> 예) 명단이 `김·이·박·최·정` 이고 9/1 에 `이` 와 `박` 이 함께 빠지면
> 8/31 `김` → 9/1 `최` → 9/2 `정` → 9/3 `김` → 9/4 `이` → 9/5 `박`

**휴일은 휴일 명단으로** — 달력에 `휴일` 이라고 적은 날은 평일·토요일 명단을 건드리지 않고
`휴일(설교)` · `휴일(백업)` 명단에서 순서대로 들어갑니다. 칸은 **연한 빨강**으로 표시됩니다.

> 휴가와 다른 점: **휴가는 그 사람만 건너뛰고 다음 사람이 서지만, 휴일은 평일 순번 자체가 멈춥니다.**
> 명단이 `가·나·다` 이고 9/1 이 휴일이면 8/31 `가` → 9/1 (휴일 명단) → 9/2 `나` → 9/3 `다`.
> 쉰 다음 예배에 원래 설 순서였던 분이 그대로 서게 됩니다.

> `휴일(설교)` · `휴일(백업)` 을 **비워 두면** 예전처럼 그 칸이 **빈 칸**으로 남고
> 메모가 붙습니다. 손으로 직접 적으시면 됩니다.
> `휴일(방송)` 처럼 역할을 붙여 적으면 그 역할만 휴일 명단으로 갑니다.

**설교자와 방송실이 겹치면 교대** — 방송실 담당을 **다음날 방송실 담당과 맞바꿉니다.**
맞바꾼 결과가 또 겹치거나 상대가 그날 휴가·휴일이면 그 다음날로 밀어서 찾습니다.
**교대는 평일끼리, 토요일끼리** — 평일 충돌은 다음 평일과, 토요일 충돌은 다음
토요일과 맞바꿉니다. 그래야 평일 사람이 토요일로 넘어가지 않습니다.

> **금요일에 겹치면 토요일을 건너뛰고 다음 월요일과 바뀝니다.**
> `토요설교`·`토요방송` 명단을 비워 두어 토요일이 평일 명단으로 돌고 있어도
> 마찬가지입니다. 토요일은 언제나 토요일끼리만 바꿉니다.

**같은 요일은 한 달에 두 번까지** — 같은 사람이 그 달 같은 요일에 세 번째로 걸리면,
그 자리를 **다른 요일 담당자와 맞바꿉니다**. **설교와 방송실에 따로** 겁니다
(설교 두 번, 방송실 두 번까지).

먼저 뒤쪽을 보고, 막히면 앞쪽을 거슬러 봅니다. **같은 달 안에서만** 찾고, 맞바꾼 뒤
양쪽 다 두 번을 넘지 않아야 하며, 그날 설교자와 방송실이 겹치게 되는 사람이나
그날 휴가인 사람은 넘어갑니다.

> **평일(월~금)끼리만 봅니다.** 토요일은 명단이 따로 돌고 그 묶음 안에는 토요일밖에
> 없어서, 순서를 어떻게 바꿔도 요일이 달라지지 않습니다. 휴일 명단으로 채운 날도 그대로 둡니다.

바꾼 칸에는 메모가 붙습니다 — 설교를 바꿨으면 설교자 줄에
`월요일 설교가 세 번째라 2026-09-22 과 순서 바꿈`, 방송실을 바꿨으면 방송실 줄에
`월요일 방송실이 세 번째라 …` 처럼 각각 붙습니다.

> 못 풀면 그대로 두고 그 칸을 **진한 빨강**으로 표시한 뒤 배정을 마칠 때 알려 줍니다.
> 평일이 주 5칸이라 그 명단 인원이 **5의 약수(1·5명)** 면 같은 요일에 같은 사람이
> 되풀이됩니다. 명단 인원을 늘리거나 줄이면 풀립니다.

**넷째 줄(수요백업·토요백업)은 겹쳐도 그냥 순서대로** — 그날 설교자나 방송실과 같은
사람이 되어도 손대지 않습니다. 다른 예배 순서라 한 사람이 맡아도 되기 때문입니다.
명단 순서가 그대로 지켜집니다.

**현관안내는 주 단위** — 수요일이 든 주마다 `현관안내` 명단에서 **세 명씩** 차례로
들어갑니다. 표 오른쪽 `I열` 의 머리글은 `현관안내(수,토)` 이고, 블록 맨 윗칸에
그 주 수요일·토요일 날짜가 `(16,19)` 처럼 붙습니다. 칸 색은 표와 같게 맞춥니다.

**현관안내는 그 주 수요백업·토요백업과 겹치지 않습니다** — 현관안내가 수요일과
토요일 현관을 맡는데, 같은 날 백업으로도 선 사람은 두 자리를 함께 할 수 없기
때문입니다. 그 주 넷째 줄에 든 사람은 그 주 현관안내에서 빠지고 다음 사람이 들어갑니다.

> 빠진 사람의 차례는 없어지지 않고 **다음 주에 그대로 돌아옵니다.** (휴가 건너뛰기와 같습니다.)

> 다만 건너뛴 그 주 한 번은 쉬게 되므로, **`수요백업`·`토요백업` 에도 들어 있는 분은
> 현관안내 횟수가 그만큼 줄어듭니다.** 세 명단에 같은 분을 많이 넣으면 차이가 커집니다.

> 겹치는 사람을 빼고 나니 세 명이 안 되면 채운 사람만 세우고, **빈 자리를 진한 빨강**으로
> 표시한 뒤 이유를 메모로 남깁니다. `현관안내` 명단 인원이 `수요백업`·`토요백업` 과
> 많이 겹치면 생기는 일이니, 명단을 넓혀 주시면 풀립니다.

**맞바꿀 상대가 없으면 그대로 둡니다.** 다른 사람을 대신 데려오지 않습니다.
그 칸은 **진한 빨강**으로 표시되고, 배정을 마칠 때 어느 날인지 알려 줍니다.
그 자리만 직접 정하시면 됩니다.

> 새벽예배가 주 6일이라, 명단 인원이 **6의 약수(1·2·3·6명)** 면 매주 같은 사람이
> 수요일(또는 토요일)에 걸립니다. 그러면 옮길 자리가 없어 교대가 안 됩니다.
> 겹침이 자꾸 풀리지 않으면 명단 인원 수를 한 명 늘리거나 줄여 보세요.
맞바꾼 칸에는 메모가 붙습니다 (셀 오른쪽 위 검은 삼각형).

**바꾼 자리를 배정 직후에도 알려 줍니다.** 검은 삼각형이 작아 못 보고 지나치기 쉬우므로,
어느 날이 바뀌었는지 안내창에 함께 나옵니다.

```
[2026-11] 배정을 마쳤습니다.

설교자와 겹쳐서 방송실을 맞바꾼 날: 10/28, 11/20, 12/1
같은 요일 세 번째라 순서를 바꾼 날: 9/15(화·설교·방송실), 9/21(월·설교)
바뀐 칸에 메모가 붙어 있습니다. 칸 오른쪽 위 검은 삼각형에 마우스를 올리면 보입니다.
```

**같은 결과가 반복 보장** — 순번을 어딘가에 저장해 두지 않고 **기준일부터 매번 새로 계산**합니다.
그래서 같은 달을 몇 번 다시 돌려도 결과가 같고, 8월 시트의 `8/31` 칸과 9월 시트의 `8/31` 칸에
항상 같은 이름이 들어갑니다.

> 이걸 지키려고 **계산은 그 달 격자보다 한 달 더 멀리까지** 돕니다. 격자 끝에서 멈추면
> 마지막 주에 생긴 겹침이 '구간 밖' 의 다음 평일을 못 보고 못 푼 것으로 남아,
> 같은 날짜가 다음 달 시트에서는 풀려 있게 됩니다. 맞바꿀 상대는 **2주 안에서만** 찾으므로
> 계산 구간을 아무리 늘려도 결과가 달라지지 않습니다.

**앞뒤 달 칸** — 첫 주·마지막 주에 걸치는 다른 달 날짜도 채우되 **회색으로** 표시합니다.

**채울 사람이 없을 때** — 그날 명단이 전원 예외면 칸을 비우고 **진한 빨강**으로 표시한 뒤,
배정이 끝날 때 어느 날인지 알려 줍니다. 명단 자체가 비어 있는 경우(예: 현관안내를
아직 안 쓰심)는 그냥 빈 칸으로 두고 안내 문구로만 알려 줍니다.

## 한 사람 것만 골라 보기

표 아래에 그 달 표에 들어간 사람 이름이 깔리고, 이름마다 체크박스가 붙습니다.
**체크하면 그 사람이 선 칸이 표시됩니다** — 설교자 줄은 **노랑**, 방송실 · 수요/토요 서브 ·
현관안내 줄은 **연한 초록**. 체크박스 위 **이름 칸도 설교자와 같은 노랑**으로 물듭니다.

**한 사람씩만 됩니다.** 다른 사람을 체크하면 먼저 체크한 것이 저절로 풀립니다.
같은 칸을 다시 누르면 아무도 선택되지 않은 상태가 됩니다.

```
이름을 체크하면 그 사람 칸이 표시됩니다 — 설교는 노랑, 방송·수요/토요 서브·현관안내는 연한 초록.
      강목사   김목사   류집사   문집사   박전도사  서집사
        ☐       ☑       ☐       ☐       ☐        ☐
      오권사   윤집사   이목사   임집사   정집사   조전도사
        ☐       ☐       ☐       ☐       ☐        ☐
```

색칠은 스크립트가 아니라 **조건부 서식**이 합니다. 누르는 즉시 반응하고,
표를 다시 만들면 체크는 모두 풀립니다.

먼저 체크한 것을 푸는 일은 `onEdit` 이 합니다. 칸에 **쓰는** 일이라 서식만으로는
안 되기 때문입니다. 그래서 새로 체크한 순간과 먼저 것이 풀리는 순간 사이에
**아주 짧은 틈**이 있습니다 (보통 1초 안쪽). 그 틈에는 두 사람이 함께 칠해 보입니다.

> 구글 시트에는 누를 수 있는 버튼이 셀 안에 없습니다. 그냥 클릭하는 것으로는
> 아무 일도 일어나지 않아서, 체크박스로 만들었습니다.
> 라디오 버튼도 없어서, 하나만 켜지게 하려면 이렇게 스크립트가 거들어야 합니다.

## 생명의 삶

배정표 맨 아래 **생명의 삶 묵상달력 열기** 를 누르면 두란노 묵상 달력이
브라우저 새 탭에서 열립니다.

> 시트 위에 창으로 띄우는 방식도 만들어 봤지만 잘 열리지 않아 걷어냈습니다.
> 셀은 그냥 눌러도 스크립트가 실행되지 않아 체크박스를 써야 했고, 편집 트리거에서
> 창을 띄우는 것이 막히는 경우가 있습니다.

**아이디와 비밀번호는 코드에도 시트에도 넣지 않았습니다.** 브라우저에 한 번
로그인해 두시면 그 세션이 유지됩니다.

## 손으로 고치고 싶을 때

결과 시트는 그냥 셀을 고쳐 쓰시면 됩니다. **다만 그 달을 다시 배정하면 덮어써집니다.**
계속 유지해야 하는 변경이면 `달력(예외자)` 에 반영한 뒤 다시 돌리는 쪽이 안전합니다.

특별새벽기도회, 부흥회, 절기처럼 **매번 따로 정하시는 날**은 달력에 `휴일` 로 잡아 두세요.
그 칸은 다시 배정해도 계속 비어 있으므로, 손으로 적어 넣은 이름이 지워질 걱정 없이 쓰실 수 있습니다.

## 개발자용

```bash
npm test        # 테스트 196개 (배정 규칙 98, 달력 파싱 10, 시트 동작 88)
npm run audit   # 전체 점검 — 12가지 설정 x 18달 + 무작위 400가지 x 14달
npm run preview # 시트 없이 터미널에서 9월 표 미리보기 (휴가·휴일·현관안내 예시 포함)
npm run build   # src/*.gs -> dist/Code.gs
```

`npm test` 는 **정해 둔 경우**를 확인하고, `npm run audit` 은 **어떤 경우에도 깨지면 안 되는
규칙**을 여러 설정 x 여러 달에 걸쳐 되풀이 확인합니다. 무작위 조합도 함께 돌려,
손으로 생각해 내지 못한 경우를 찾습니다. 확인하는 규칙은 `tools/audit.js` 맨 위에 적어 두었습니다.

> 배정 규칙을 손볼 때는 `npm test` 와 `npm run audit` 을 **둘 다** 돌려 주세요.
> 실제로 아래 네 가지는 테스트는 통과하는데 점검기가 잡아낸 것들입니다.
> - 마지막 주 겹침이 구간 밖을 못 봐서 같은 날짜가 달마다 달라지던 문제
> - `휴일(현관안내)` 가 달력에 저장될 때 역할이 날아가던 문제
> - 통째로 기준일 앞인 달도 거의 빈 표로 만들어지던 문제
> - 요일 설정에 오타가 나면 아무 설명 없이 빈 표가 나오던 문제

| 파일 | 역할 |
|---|---|
| `src/Rotation.gs` | 배정 규칙 (시트 API를 안 씁니다. Node 로 그대로 테스트됩니다) |
| `src/Sheets.gs` | 설정·명단·예외 읽기 |
| `src/Calendar.gs` | `달력(예외자)` 탭 그리기/읽기, 달마다 저장 (`_달력저장` 숨김 탭) |
| `src/Render.gs` | 월별 표 그리기 |
| `src/Setup.gs` | 초기 탭 만들기 |
| `src/Qt.gs` | 묵상 달력 링크 |
| `src/Menu.gs` | 시트 상단 메뉴, `onEdit` (달력 연월 칸 고르기 · 이름 체크 한 사람씩만) |

`test/sheets.test.js` 는 구글 시트 API 를 흉내 낸 껍데기(`test/fakeSheets.js`) 위에서
초기 설정부터 월별 표 생성까지 실제로 한 번 돌려 봅니다.
값·메모·병합·바탕색·조건부 서식, 그리고 메뉴와 안내창 글까지 검사합니다.
